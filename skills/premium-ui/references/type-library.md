# Type library

Picking a face from memory lands on the same dozen every time (see
direction-finding §4, **Faces**). This library gives each genre a wide,
pre-checked shelf so the choice comes from the direction, not from habit.

Every face below is on Google Fonts and was checked for Turkish
(ğ Ğ ş Ş ı İ ç Ç ö Ö ü Ü) with `scripts/check-fonts.py`. Lists are
**alphabetical on purpose**: position says nothing about quality, so never
take the first entry. A face outside this file is fine if it passes the
same script.

## How to choose

1. From the direction's metaphor, decide the genre for the **UI face**
   (body, labels, tables) and, if the direction needs one, a **display
   face** for headings or the emphasis device. Many strong directions use
   one family in two weights.
2. In that genre, read the notes and pick the face whose note matches the
   metaphor ("signage", "ledger", "chalkboard"), not the one you recognise.
   If two fit, prefer the one not used in this conversation or project.
3. Pair across genres, not within: a grotesk with a slab or a serif, a
   humanist sans with a mono. Two similar sans faces look like a mistake.
4. Panels are read for hours: the UI face comes from groups 1–3, 7 or
   (for data-heavy screens) 10. Display, condensed, wide, rounded and
   hand faces are for headings, numbers and short labels.
5. Check weights: some faces here have only one weight (noted as *single*).
   They can't carry weight-contrast emphasis.
6. Run `python3 scripts/check-fonts.py "Face A" "Face B"` on the final
   pair, even from this list, before writing the board.

Faces marked † are on the overused list in direction-finding §4: at most
one per board, and only with a product reason.
